## Architecture

| Component | Detail |
|---|---|
| `index.html` | Single-file static dashboard. All CSS, HTML, JS inline. No framework. |
| `data/tickets.json` | Generated by `generate_dashboard.py`. Fields: `task_num`, `summary`, `status`, `priority`, `days`, `analyst`, `category`, `created`, `team`. |
| `generate_dashboard.py` | Parses OSM report → writes `data/tickets.json`. Fails workflow run on SAASIT session expiry. |
| `import_osm_report.py` | Imports raw OSM Excel/CSV export → intermediate format. |
| `login.py` | Oxford SSO login via Playwright. Saves `session.json`. |
| `Refresh Session.bat` | Pulls latest `login.py` from GitHub and runs it to refresh session. |
| `Update HRIS Dashboard.bat` | Runs the full pipeline locally if needed. |
| `.github/workflows/` | GitHub Actions — hourly cron Mon-Fri 7-16 UTC on self-hosted runner (DESKTOP-MJDJM64). |
| `cloudflare-worker/` | Source for Cloudflare Worker proxy (Refresh button — PAT stored as Worker secret). |
